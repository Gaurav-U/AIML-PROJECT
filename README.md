# 🤖 AI-Powered Smart Email Management System

An intelligent email management system built using Machine Learning, NLP, and Transformer-based models to classify emails, detect spam, and automate email organization.

---

## 🚀 Features

* Spam Email Detection
* Smart Email Classification
* NLP Text Processing
* TF-IDF Feature Engineering
* Machine Learning Models
* BERT-Based Deep Learning
* Performance Evaluation & Comparison

---

## 🛠️ Technologies Used

* Python
* Scikit-learn
* Transformers
* TensorFlow / PyTorch
* Pandas & NumPy
* Google Colab

---

## 📂 Project Workflow

1. Dataset Creation
2. Text Preprocessing using NLP
3. Feature Extraction with TF-IDF
4. ML Model Training
5. BERT Model Implementation
6. Performance Evaluation

---

## ▶️ How to Run

1. Open the notebook in Google Colab
2. Enable GPU Runtime
3. Run all cells sequentially
4. View predictions and outputs

---

## 📊 Results

The project successfully classifies emails, detects spam messages, and compares Machine Learning models with Transformer-based Deep Learning models.
